To run : `docker-compose up --build` at the root directory.

Setup new microservice? here are some quick cmd line-

 1. mysql : `npm i --save mysql2 nats typeorm @nestjs/typeorm @nestjs/microservices class-transformer class-validator`

 2. mongo : `npm i --save mongoose @nestjs/mongoose @nestjs/microservices class-transformer class-validator nats`

 3. cache-redis : `npm i --save redis@3.1.2 cache-manager-redis-store @nestjs/cache-manager`

 4. nats :  `npm i nats rxjs`

 5. Validation : `npm i class-validator class-transformer`
